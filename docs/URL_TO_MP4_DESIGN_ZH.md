# 单 URL 到 MP4：执行设计（2026-09-17）

当前历史状态：下载、Whisper/VAD、说话人分组、Codex 翻译、CosyVoice3 和渲染模块存在，但上一轮只完成手工清单驱动的三句试制，不能称整条自动管线完成。

本轮目标：一个脚本接受英文 YouTube URL，下载最高可用源片，自动分段、选择同说话人的参考候选、翻译、生成中文、定位当前英文字幕，生成一份 H.264/AAC MP4。用 73XAgADpBqY 整片实跑验证。自动候选与人工确认保持不同状态，脚本不自动上传或发布。

## 最新声音与交付规则

- 每段完整英文先行，在该段英文发声结束点插入中文，英中之间不添加静音。不再等待整个画面句组的静音尾巴结束才开始中文。
- 中文之后接回该段剩余原声音频，包括源片自然停顿/环境声，随后进入下一段；不额外添加一秒停顿。全部原声 PCM 保序保留，中文不变速、不截词。
- 新时间线显式记录英文结束采样、中文起止采样和源音频尾段位置。连续画面保留每个原始帧，按实际中文时长伸展输出时间。
- 唯一交付视频为 `output.mp4`（H.264、yuv420p、AAC、faststart）。工作目录保留下载的原文件、参考音、逐句配音、源/组合 PCM、定位和检查证据；不生成第二份 MKV 或停帧对照片。
- 中文 TTS 若自带明显前导静音则报告待复核，不能以任意裁音方式截掉起始发声。零人为间隔与模型自身发声起点分别检查。

## 自动入口

脚本有明确工作目录和输出位置，默认沿用本机配置中的固定模型；预检模型文件、FFmpeg/Node/Codex 和磁盘余量；OCR 调用时记录连接或服务错误。每个步骤写请求、输入哈希、输出哈希和完成状态；失败保留原因和已完成步骤，恢复只能复用哈希匹配的结果，不能覆盖旧成片。

复用现有模型 worker 与翻译适配器。模型自动说话人标签只表示候选，不能当作已确认角色姓名；不同标签不得借用参考音。对话及紧随的 said/asked 旁白合为一段，内部角色音频分别合成再拼接。无法取得本说话人参考、切点跨发声、字幕定位不可靠或模型失败时停止并提供可复核原因。

英文字幕采用实际 OCR 页面及源帧范围，不能用全片框并集。每页通过对应英语文字匹配定位，跟随源帧到输出帧的映射；不同页面分别绘制中文。原画面尺寸及英文保留，不重绘英文、不增底栏、不插帧。没有可靠页面定位的输入不得伪装成字幕通过。

## 验证

1. 单元测试：中文开始采样恰等于英文发声结束后的输出采样；完整原声前段/尾段保留，零新增英中间隔；旧时间线仍可审计。
2. 编码测试：只出现一份交付 MP4，H.264/AAC/yuv420p；尺寸、帧数、PTS、全量解码、音频时长和编码前 PCM 内容检查通过。
3. 自动编排：真实下载 URL、实际模型输出、自动字幕页及同说话人参考绑定；失败/恢复和不覆盖版本测试。
4. 整片实跑：保存命令、阶段状态、耗时、来源/模型/输出哈希及截图。技术结果、逐页视觉检查、真人试听和正式验收分开报告。

代码完成、整片技术跑通不代表所有视频都能无需复核发布；ASR/聚类/翻译/克隆均可能需要人工修订。保留 REVIEW，不自动填写人工通过。

整片扩展时取消试制工具的 0.4× 硬拒绝阈值：低于该值的句组写入 `motion_review_units` 并保持 REVIEW，不能加速/截短配音或改用停帧来隐瞒时长差。个别 CosyVoice 输出本身的前导噪声/静音仍需试听，零插入间隔不等于已经证明首个字的主观听感无等待。
