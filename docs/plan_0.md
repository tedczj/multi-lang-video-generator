# 轻量 MySQL、串行执行的视频流水线设计

> 2026-09-11：本大纲对应的 [完整开发计划](DEVELOPMENT_PLAN_ZH.md) 及 [第一期](kickoffs/PHASE_1_KICKOFF_ZH.md)、[第二期](kickoffs/PHASE_2_KICKOFF_ZH.md)、[第三期 kickoff](kickoffs/PHASE_3_KICKOFF_ZH.md) 已补齐。以下保留原始大纲；文档交付不代表功能已实现。

  ## 1. 设计基线与文档交付

  采用单个 Mac 主控、任务串行执行、独立模型 worker、单实例 MySQL Docker。三期均按单写入者设计，不实现并发调度、数据库版本锁、分布式租约和跨表
  事务编排。

  保留 MySQL 自身的 InnoDB、单条语句自动提交和崩溃恢复能力。简化应用层事务管理，不关闭数据库的基本持久化保障。

  各期 kickoff 包含前置条件、任务顺序、接口、参考源码、验收命令和完成标准，双向引用完整计划。原始大纲和历史报告保留为参考，不计入当前验收。

  ### 数据与文件职责

  - MySQL：资产、流程、执行版本、产物索引、血缘、模型回执索引、选择记录、质量状态、日志事件和发布记录。
  - 文件系统：视频、音频、截图、字幕、掩膜、完整请求响应、执行清单及原始日志。
  - JSONL：每视频可读日志，由主控单写入，可从数据库事件重建。

  详细设计提供必要表结构、字段、唯一约束和查询索引，不为假设中的高并发增加表或调度机制。

  ### 串行执行与基本恢复

  - 主控持有一个操作系统文件锁；第二个写入命令明确报“已有任务运行”。查询命令不受影响。
  - worker 只返回结果，不直接写数据库。
  - 每个节点按既有最大版本号加一分配版本，保留唯一约束；每次执行另有唯一 execution ID。
  - 节点按依赖顺序执行，等待上一个节点完成；OCR 对照实验也串行运行。
  - 每次有效 retry 创建新版本并重新调用业务，不复用旧推理结果。

  结果保存顺序：

  > 完整写入文件并校验 → 封存执行清单 → 逐条登记产物和血缘 → 最后标记执行成功。

  中途失败时，部分登记数据不能供下游使用。recover 根据完整清单补齐登记；无完整结果的执行标记为中断，由新版本重试。数据库连接中断后先核对
  execution ID，不直接重复调用模型。

  备份在暂停任务、取得同一运行锁后进行，保存数据库导出及对应媒体文件；不实现在线增量备份或分布式恢复。

  ## 3. 模块、业务流程与开源参考

  项目模块分为：

  - 基础模块：CLI、配置、MySQL 访问、文件存储、执行器、版本血缘、日志、基本恢复。
  - 业务节点：媒体准备、字幕与语音分析、归句、翻译、参考音频、TTS、去字幕、时间线、排版、合成、QA、发布。
  - 适配器：外部工具和模型调用、worker 请求与结果转换。
  - 工程配套：Compose、SQL 迁移、契约、测试、素材和证据目录。

  业务流程：

  > 下载／本地导入 → SHA-512 归档 → 探测与归一化 → 字幕提取 → 语音分析 → 归句 → 翻译 → 克隆配音 → 音频检查 → 去字幕与样式处理 → 时间线 → 双语
  > 排版 → 合成 → QA → 发布。

  每个节点写明输入输出、步骤、默认参数、失败条件、重试粒度、日志、测试编号、所属期及具体源码参考。

  核心选择保持：

  - 翻译：本机 Codex CLI，gpt-5.6-terra、medium；连续完整语句合批，默认最多 8 段或 6,000 源文字符，按稳定 ID 拆分。
  - 克隆：官方 CosyVoice3 Fun-CosyVoice3-0.5B-2512，按说话者准备参考音频，逐句生成并测量真实采样数。
  - 编排：英文结束后等待 1 秒播放中文，中文结束后至少等待 1 秒；优先使用原片空档。
  - 定格：使用两句讲话之间最后一个安全整帧切点；无安全切点时重新归句或复核。
  - 排版：英文在上、中文在下；保留原片内容及多余空档，不压缩语音。

  ## 4. 测试与日志

  每个用例给出环境、素材、步骤、命令、独立预期、断言和证据位置。

  保留必要测试：

  - 单元测试：血缘、版本递增、强制重试、翻译批次拆分、音频拼接、时间线、契约和质量门禁。
  - MySQL 集成：初始化、迁移、实际读写、唯一约束、容器重启后数据保留、断连恢复、备份还原和资源占用。
  - 串行运行保护：第二个写入进程被拒绝，退出后锁自动释放。
  - 真实媒体：FFmpeg 无损逐帧及 PCM 逐采样校验，覆盖空档、片尾、非整数帧率、VFR 和音画偏移。
  - 真实模型与成片：下载、OCR、Codex、CosyVoice3、去字幕、完整输出。
  - 故障：进程被杀、超时、磁盘满、半写入、输出篡改及基本恢复。

  不设计多主控竞争、死锁重试和分布式事务测试。正式验收不使用 SQLite 或 mock 替代真实 MySQL 和模型。

  日志统一记录资产、run、execution、节点、策略、代码、参数、输入输出引用、耗时和终态；额外记录翻译批次、TTS 参考音频及采样数、时间线补帧依据、
  保存中断与恢复动作。

  翻译、音色和画面采用自动检查加有记录的人工复核；缺少必选检查不能标记 PASS。
